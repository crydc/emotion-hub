# 情绪涨跌逻辑

一句话总结：**情绪值向量 v（10 维，-1..1）→ 每拍先衰减、再叠加线索、再算吸引子 → 得到 13 种情绪的权重。**

## 三个基本操作

### 1. 衰减（回基线）

每一拍：

```
v = BASE + (v - BASE) × 0.92
```

也就是每拍往基线靠近 8%。从 1.0 开始：0.948 → 0.900 → 0.856……

另有按真实时间的衰减：`k = 0.5^(经过分钟/120)`，两小时回到一半距离。心跳每分钟一次时这段影响很小，主要兜底长时间没跑的情况。

### 2. 线索（一句话推动）

`cue(text)` 用关键词给 10 维打分（−1..1）。比如“夸/好看/乖” → 开心+1、温柔+0.6；“没理/不回/好久” → 委屈+1、想找人+1。

然后：

```
v = BASE + (v - BASE) × 0.92 + 线索 × 0.9
```

### 3. 吸引子（网络算权重）

现代霍普菲尔德：`x ← Σ softmax(β·sim(x, P_j)) · P_j`，迭代到稳定。得到 13 个权重，按大小排。

## 每种情绪

| 情绪 | 主要线索 | 特殊升起 | 表现 |
| --- | --- | --- | --- |
| 开心 | 夸、笑、喜欢 | 得意/期待带动 | 轻快，会接梗 |
| 温柔 | 夸、乖、想你 | — | 软，会关心 |
| 黏人 | 想找人 | 孤独、期待、吃醋、害羞带动 | 话多，讨一句好 |
| 期待 | 想你、找你 | 黏人带动 | 追着问、等消息 |
| 得意 | 显摆、被夸 | — | 嘴上还嘴硬 |
| 吃醋 | 别人、别的鱼 | 生气带动 | 阴阳两句 |
| 想怼人 | 插件、装、怼 | 生气、吃醋、得意带动 | 一句戳心，语气挑 |
| 害羞 | 被亲近 | — | 说完换话题 |
| 生气 | 不理、算了 | — | 很冲，可能不理 |
| 孤独 | 很久没人说话 | **没人说话时长直接加** | 轻，带委屈 |
| 难过 | 委屈累积 | 孤独带动 | 短，声音低 |
| 怕 | 被丢下 | — | 问你在不在 |
| 犯困 | 累、困、睡觉 | — | 短，懒洋洋 |

### 孤独怎么涨

只有在「没有新消息」的 tick 里才涨：

```
超过 120 分钟后：每多 1 小时，孤独 +0.12（封顶 +0.45）
```

测过：3 小时 ≈ 0.44，6 小时 ≈ 0.77，10 小时封顶。

| --- | --- |

| 得意 | 想怼人 +0.2、开心 +0.15 |

| 害羞 | 黏人 +0.12 |
| 黏人 | 期待 +0.1 |

## 心跳用什么

`heartbeat.mjs` 取权重最高的那个情绪：

- 过了阈值 `0.35`（想怼人用 `0.25`）才继续算概率；
- `e = 1 - e^(-3.2·base)`，`p = 1 - (1-e)^(1 + 憋着次数×0.6)`；
- 掷骰成功 → 写 `wake.flag`，由上层 agent 看上下文后自己开口。

## 提醒

这些规则都是**手写的**，不是学出来的，数值可以按喜好调；情绪只负责语气和“要不要开口”，不替代模型本身。
